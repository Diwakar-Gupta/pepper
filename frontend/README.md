# Pepper frontend

React 18 + React Router + Tailwind, bundled with Parcel. Deployed as a static site to GitHub Pages under `/pepper/`.

## Develop

```bash
yarn install
yarn start          # http://localhost:1234/pepper/
```

Start the judge too (`python3 ../judge/pepper_judge.py`) to run code. `localhost` origins are always allowed by the judge.

## Build & deploy

```bash
yarn build          # dist/ (also writes dist/404.html so deep links work on GitHub Pages)
yarn deploy         # build + push dist/ to the gh-pages branch
```

Normally you don't deploy by hand: `.github/workflows/deploy.yml` does it on every push to `main`.

## Layout

```
src/
  App.jsx                 routes
  constants.js            base path, judge URL, language list, starter templates
  contexts/JudgeContext   finds the local judge (polls 127.0.0.1:<port>/health)
  lib/data.js             loads JSON from public/database
  lib/judge.js            judge HTTP client
  lib/storage.js          localStorage: code drafts, progress, preferences
  pages/                  Home, Course, Module, Lesson (article/video), Problem
  components/problem/     editor, console, statement, submissions
public/database/
  courses/meta.json                     course list
  courses/<course>/meta.json            categories -> modules
  courses/<course>/<module>.json        items: problems, articles, videos
  problems/<slug>.json                  statement, samples, templates, editorial, videos
  articles/<slug>.json                  notes
  testcases/<slug>/testcase{input,output}N.txt
  images/                               images from the archive
```

The database is generated by `../scraper`; hand edits to test cases are preserved by the scraper.

## Notes

- Code drafts, the chosen language, editor settings and solved problems are kept in `localStorage`, so the site works
  (minus running code) without the judge. Solved status is also merged in from the judge's database.
- The judge is only probed after you open a problem (or once you've used it before), so visitors who never run it
  don't get a browser "local network access" prompt.
